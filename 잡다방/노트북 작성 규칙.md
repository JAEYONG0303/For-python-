# 노트북 작성 규칙

지금까지 쓰던 방식을 그대로 정리한 것입니다.
`✅ 이렇게` 는 원래 쓰던 방식, `➕ 이렇게 하면 더 좋음` 은 읽기 편하도록 조금 다듬은 부분입니다.

---

## 1. 마크다운 제목 계층

깊이별로 역할이 이미 나뉘어 있습니다. 이 계층을 유지하면 노트북 목차만 봐도 흐름이 보입니다.

```markdown
# 지도학습 - 다중선형회귀      ← 노트북 주제, 맨 위 한 번만
## 1. 데이터 확인 및 전처리     ← 큰 단계, 번호 붙임
### 1. 데이터 품질 검사         ← 세부 작업
#### 인사이트                   ← 결과 해석
```

➕ **`#### 인사이트`는 결론을 한 줄로 먼저 쓰기.** 지금은 근거만 적혀 있는 경우가 있는데,
나중에 다시 볼 때는 "그래서 뭘 했나"가 먼저 필요합니다.

```markdown
#### 인사이트

- **스케일링 필요** — 길이·높이·두께의 단위 차이가 커서 회귀계수 비교가 불가능
```

## 2. import 셀


➕ **그룹 순서를 고정.** `hossam` → 데이터/시각화 → 통계 → sklearn 순.
어느 노트북을 열어도 같은 자리에 있으면 찾는 시간이 줄어듭니다.

## 3. 주석

한글 주석, 코드 위에 한 줄. 이미 하고 있는 방식입니다.

```python
# 원본 데이터 프레임 참조
# -> 이후 코드를 고정으로 사용하기 위해 객체 이름을 df로 통일하는 용도
df = origin
```

➕ **"무엇을"이 아니라 "왜"를 적기.** 코드를 읽으면 알 수 있는 건 생략합니다.

```python
# 나쁨 : 무게 컬럼에 로그를 씌운다      ← 코드에 이미 보임
# 좋음 : 무게가 오른쪽으로 치우쳐 있어 정규성 확보용
df1['무게'] = np.log1p(df1['무게'])
```

➕ **같은 주석을 두 번 쓰지 않기.** 셀을 복사하다 보면 아래처럼 겹치는 경우가 생깁니다.

```python
# IQR, 이상치 경계, 이상치 수, 이상치 비율
# IQR, 이상치 경계, 이상치 수, 이상치 비율     ← 중복
```

➕ **구분선 주석은 셀을 나눌 신호.** `# ----------` 로 셀 안을 나누고 있다면
대부분 셀 두 개로 쪼개는 편이 낫습니다. 위쪽만 다시 돌려볼 수 있게 됩니다.

## 5. 시각화 셀

이미 쓰고 있는 형태를 그대로 둡니다.

```python
figsize = (1280/my_dpi, 720/my_dpi)

sb.boxplot(data = df1[['길이','높이','두께']])
```

```python
ax.set_title('독립변수 분포')
```

## 6. print 출력

값 확인은 `print("이름 =", 값)` 또는 f-string을 쓰고 있습니다. 둘 다 쓰이는데,

➕ **f-string으로 통일.** 콤마 방식은 붙는 공백이 눈에 걸립니다.

```python
# 지금
print("size =", size)
print(i, "번째 데이터 -> 총합 =", total, "평균=", average)

# 통일
print(f"size = {size}")
print(f"{i}번째 데이터 -> 총합 = {total}, 평균 = {average:.2f}")
```

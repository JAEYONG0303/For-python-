## 1. 오늘 배운 내용

- **데이터 수집**
    - 여러 형태의 데이터가 여러가지 기술로 전송됨

- **데이터 전송**
    - 벌크(bulk)형
        ■ 존재하는 데이터를 정리해 추출하는 방법
        ■ DW에서는 주로 벌크형
    - 스트리밍(streaming)형
        ■ 실시간으로 데이터륿 보내는 방법
        ■ 모바일 애플리케이션, 임베디드 장비 등에서 사용
        ■ 빅데이터 세계에서는 스트림 처리(실시간 처리)형 방식으로 처리
        ■ 장기적 데이터 분석에는 적합하지 않음(데이터 양이 너무 많아짐)
    
    ---> 그래서 **분산 시스템** + **배치처리 구조**의 필요성 증대

- **분산 스토리지**
    - (여러 컴퓨터 + 디스크)로 구성된 시스템
    - 객체 스토리지가 대표적(한 덩어리에 이름 부여하여 파일로 저장 ex. Amazon S3)
    - NoSQL DB도 가능 ---> 어플리케이션 데이터(로그..인감...?) 측면

- **분산 데이터 처리**
    - MapReduce: 많은 데이터를 나눠서 처리한 뒤, 같은 항목끼리 결과를 합치는 방식
        ■ 여러 컴퓨터에서 동시 수행 가능
